# M1 application foundation

25 October 2026. The application shell now runs on Svelte/Vite/TypeScript and a direct Three.js scene, using the M0 WASM engine in a module worker.

## Implemented

- Observatory layout: context bar, compact tool dock, scene, inspector, paused timeline, startup example and explicit UTC moment entry.
- Three lifecycle: resize, one canvas, frame-correct body/reference directions, three camera destinations, click versus drag, keyboard camera commands, WebGL2 fallback, context restoration, and resource disposal.
- Typed commands and runtime Zod schemas for requests/results. Immutable published state, atomic snapshots, generation/revision guards, invalid draft handling, worker retry and listener cleanup.
- Working body selection through canvas and keyboard-accessible list, numeric inspector, day stepping, anchor return, and scene layer controls for implemented geometry.
- Pinned framework/renderer/tooling, lint/format configuration, and GitHub CI for checks, tests, asset integrity, production build and Chromium workflows.
- Source/licence access and persistent schematic-scale label. Full local civil-time/search, houses, catalogue stars, interpretation content and timeline features remain assigned to later milestones.

## Validation

- `npm run check`: zero Svelte errors/warnings; TypeScript passes.
- `npm run lint`: passes.
- `npm test`: 53 tests pass, including the 37 M0 tests and state/protocol checks, with an explicit external-mutation regression for frozen snapshots.
- `node scripts/verify-assets.mjs`: passes after checkout.
- `npm run test:browser`: production build and three Chromium workflows pass: example/selection/viewpoint/anchor, real WebGL context loss/recovery with numeric selection preserved, and UTC/coordinate form entry.
- Independent browser probes also verified canvas picking versus dragging, Home viewpoint synchronisation, mount/dispose/remount, harmless late calls, and disabled-WebGL fallback.
- `npm audit`: no known vulnerabilities after updating the script runner dependency.

Independent reviews found no blocking scene or store/protocol issues. Minor lifecycle guards were added after review. A shared Vite optimiser-cache collision during concurrent development previews was resolved by isolating cache identities; acceptance browser checks use the built production artefact.

The production UI bundle is approximately 736 KB raw / 195 KB gzip, plus the approximately 145 KB worker, 392 KB WASM and the separately cached ephemeris data. The build's Node `module` externalisation notice belongs to an unreachable Emscripten Node-only branch; the actual production browser-worker tests pass. Broader browser/GPU/accessibility/performance acceptance remains in M8/M9.

## Local development

```text
npm ci
npm run dev -- --host 127.0.0.1
```

For browser tests, first install Chromium with `node scripts/install-browsers.mjs chromium`, then run `npm run test:browser`. The command rebuilds and serves the actual production bundle. See the implementation status for branch/PR integration.
