# M2 — Numerical chart and input

Completed 25 October 2026 on `codex/m2-chart-input`, based on the reviewed M1 integration. Main remains unchanged.

## Delivered

- Local Gregorian date/time input with explicit IANA zone or manual minute offset. Folds require an occurrence choice; gaps provide an explicit correction action. UTC preview and range checks apply after conversion. Unknown birth times use visibly provisional local noon.
- Reproducible IANA 2026e/backzone build retaining 598 distinct identities and historical second offsets. The build independently checks 64,774 compiled periods with Python ZoneInfo and every Moment packing round trip. Two builds produced the same artifact hash. See [build instructions](../timezone-build.md).
- Explicit place search, editable coordinates, comprehensive geographic zone lookup, multiple-candidate handling and manual recovery. Only place text or coordinates reach the server. API schemas reject other fields and duplicate query keys. Bounded caches, six-second upstream timeout and attribution are included. Geographic hashes are pinned in `api/data-manifest.json`; upstream boundary release metadata is unavailable, so no release number is invented.
- Deliberate globe selection with real Natural Earth coastlines. Dragging never changes the observer. A click proposes coordinates to the form; applying the form commits them. Picking preserves the originating form's civil fields and birth/exploration purpose.
- Immutable session birth anchor, separate exploration context, return to birth instant at the current observer, and restore original birth context. A location edit preserves the UTC instant unless the user explicitly chooses to preserve the local clock.
- Indexed longitude house membership including reverse polar partitions, tropical sign membership and five major longitude aspects with explicit orbs. Renderer settings cannot affect these results. Geocentric calculations are reused for observer/system edits; horizon and houses are recalculated.

## Scope and limits

Current geographic boundaries are not a historic atlas. Backzone retains additional records but cannot certify historic birth records; future civil rules are projections. These warnings and manual corrections remain visible.

Open-Meteo's credential-free endpoint is the noncommercial development default. Public commercial deployment requires an eligible provider configuration. Production hosting/rate limiting is a release gate; Vite's development and preview middleware currently hosts the API for local work and CI. Stars, zodiac geometry, house rendering, constructions, complete interpretation content and timeline trails remain assigned to later milestones.
